# Production Data Analysis Dashboard -- Excel

## Project Overview

This project presents an interactive **Production Data Analysis
Dashboard** developed in Microsoft Excel to analyze production costs,
production volumes, manager task completion, and product-level
performance.

The dashboard transforms raw production data into an interactive
analytical view using **Power Query Editor, VLOOKUP, added/derived
columns, Pivot-based analysis, charts, and slicers**. It is designed to
help identify production trends, cost differences, and performance
patterns across products, managers, time periods, regions, genders, and
age groups.

## Objectives

-   Analyze total production cost across different product types.
-   Compare average production cost per unit by product type.
-   Track production volume across months and years.
-   Evaluate the number of tasks completed by individual managers.
-   Enable interactive filtering of production performance using
    multiple slicers.
-   Convert raw production data into clear and decision-oriented visual
    insights.

## Dashboard Highlights

The dashboard contains four major visualizations:

### 1. Total Production Cost by Product Type

A column chart comparing the total production cost for: - Automobiles -
Electronics - Furniture - Machinery

### 2. Number of Tasks Completed by Managers

A horizontal bar chart ranking managers based on the number of completed
tasks.

### 3. Total Units Produced by Year/Month

A time-series line chart showing monthly production volume across 2023
and 2024, making production peaks and declines easy to identify.

### 4. Average Production Cost per Unit by Product Type

A pie chart showing the average production cost per unit and its
relative share across product categories.

## Interactive Slicers

The dashboard includes interactive slicers for:

-   **Quarter**
-   **Age Group**
-   **Gender**
-   **Region**

These slicers allow users to dynamically filter the dashboard and
analyze production performance from different business perspectives.

## Key Performance Indicators & Insights

### Production Cost

-   **Automobiles** have the highest total production cost at
    approximately **1.2 million**.
-   **Machinery** follows with approximately **0.94 million** in total
    production cost.
-   **Furniture** accounts for approximately **0.72 million**.
-   **Electronics** has the lowest total production cost among the four
    categories at approximately **0.62 million**.
-   Based on the dashboard values, total production cost across the four
    product categories is approximately **3.48 million**.

### Average Production Cost per Unit

-   **Furniture** has the highest average production cost per unit at
    approximately **180**, representing about **34%** of the displayed
    average-cost mix.
-   **Automobiles** follow at approximately **141** per unit,
    representing about **26%**.
-   **Machinery** has an average cost of approximately **109** per unit,
    representing about **20%**.
-   **Electronics** has the lowest average production cost per unit at
    approximately **108**, also representing about **20%**.

### Production Volume Trend

The monthly production trend shows significant fluctuations:

-   The highest production level shown is **4,803 units in November
    2023**.
-   **February 2024** records another strong production level of **4,127
    units**.
-   Production falls considerably in **April 2024**, reaching **1,528
    units**.
-   Production rises again in **June 2024** to **3,537 units**.
-   The displayed period ends at **1,379 units in September 2024**.
-   Overall, the dashboard indicates noticeable month-to-month variation
    rather than a consistent upward or downward production trend.

### Manager Task Performance

The manager task chart shows substantial variation in completed tasks:

-   **Nancy Grey** has the highest number of completed tasks with
    **37**.
-   **Jane Smith** follows with **18**.
-   **John Doe** completed **13** tasks.
-   **Mike Brown** completed **11** tasks.
-   **Sarah Lee** has the lowest displayed count with **5** tasks.

This comparison helps identify differences in task completion levels
across managers.

## Tools & Techniques Used

### Microsoft Excel

Used as the primary tool for data preparation, analysis, visualization,
and dashboard development.

### Power Query Editor

Used for: - Data cleaning and transformation - Preparing raw data for
analysis - Structuring data before dashboard creation

### VLOOKUP

Used to retrieve and combine relevant information from supporting data
tables based on matching values.

### Column Addition / Derived Columns

Additional columns were created to support analysis, categorization, and
dashboard calculations.

### Pivot-Based Analysis

Used to summarize production data by product type, manager, month, and
other relevant dimensions.

### Excel Charts

The dashboard uses: - Column chart - Horizontal bar chart - Line chart -
Pie chart

### Excel Slicers

Interactive slicers were added for: - Quarter - Age Group - Gender -
Region

## Data Analysis Workflow

1.  Imported and reviewed the raw production data.
2.  Cleaned and transformed the dataset using Power Query Editor.
3.  Added required columns for analysis and categorization.
4.  Used VLOOKUP to retrieve and combine relevant information.
5.  Created summarized views using Pivot-based analysis.
6.  Developed charts to represent production cost, production volume,
    average unit cost, and manager performance.
7.  Added interactive slicers for dynamic filtering.
8.  Designed the final Excel dashboard for business-oriented analysis.
9.  Reviewed the dashboard to identify major production and cost
    insights.
